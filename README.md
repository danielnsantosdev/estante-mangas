# 📚 Estante de Mangás

App para anotar o último capítulo lido de cada mangá, sincronizado entre PC (Windows) e celular (Android).

## ⬇️ Baixar
Vá em **Releases** (à direita, nesta página) → baixe:
- **EstanteMangas.apk** → Android
- **EstanteMangas-Setup.exe** → Windows

O acesso é só para convidados.

## Como o app é gerado
Toda vez que um arquivo é enviado para este repositório, o GitHub Actions compila o app sozinho
(`.github/workflows/build.yml`) e publica os instaladores em Releases.
